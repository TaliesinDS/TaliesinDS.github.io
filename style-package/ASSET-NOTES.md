# Asset Notes

This style package includes copies of font and icon assets from the main repo so it can travel as a self-contained “main body text” bundle.

## Fonts

Copied from:
- `/assets/fonts/`

Used as:
- `EB Garamond`
- `EB Garamond SC 12`

License/source context:

## Icons

Copied from:
- `/assets/icons/`
- `/_includes/icons/`

The site uses inline SVG icons (not an icon font). The copied icon sets include the same SVGs used by the Jekyll includes.

License/source context:
- This repo currently doesn’t enumerate icon licenses in `/licensing.md`. If you redistribute this style package separately, verify the icon licensing for the SVGs under `assets/icons/`.
