# Style Package

Start here: `STYLE-GUIDE.md`.

Contents:
- `STYLE-GUIDE.md`: LLM-readable editorial + typography rules for main body text (framework-agnostic)
- `main-body.css`: convenience CSS snapshot; apply it to a `.prose` container
- `assets/fonts/`: copies of the site’s self-hosted fonts
- `assets/icons/`: copies of the site’s SVG icon assets
